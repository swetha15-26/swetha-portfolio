# Swetha Arulkumar Portfolio

A polished, pastel-toned one-page portfolio website for Swetha Arulkumar, designed for recruiters and built as a free, deployable static site.

## Features
- Light olive green + pastel sky palette
- Professional summary and personal branding
- Sections for achievements, certifications, and contact details
- Responsive layout with animated floating cards
- Ready to deploy to GitHub Pages

## Deploy for free
1. Create a GitHub repository and push the files in this folder.
2. In the repository settings, enable GitHub Pages for the main branch.
3. Open the published URL to share it with recruiters.

## Local preview
Run a simple local server from this folder:

```bash
python -m http.server 8000
```

Then open http://localhost:8000 in your browser.
